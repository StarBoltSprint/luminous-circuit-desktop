# Luminous Circuit — Desktop

Pack-built living crystal city in a **Windows desktop window**. Same Core Spire as the mobile vessel. Walk, Howl, Talk, Map, Log.

**Powered by xAI & YOU.** Not an official xAI product. Not Msg 1. Not a node SKU.

Story beat: *Land true. The circuit answers.*

## Play (desktop)

- **WASD / arrows** walk. **Shift** sprint. **E / T** talk. **H / Space** Howl (hold through the gold).
- **Mouse** look (click the city to capture). Esc releases.
- **Map**, **Log**, **Trading Place** — same civic loop. `$BOLT` is witness only.

## Run

```
npm i
npm run dev
```

That opens the Electron window on the Vite city. Web-only: `npm run dev:web`.

```
npm run typecheck
npm run dist
```

`dist` writes a Windows installer under `release/`.

## What this is

Desktop fork of Core Spire (`src/game`, `src/components`). No Grok preview host. No app-builder chrome.

Mobile snapshot lives at [luminous-circuit-mobile-version-](https://github.com/StarBoltSprint/luminous-circuit-mobile-version-). This repo is the **desktop vessel**.

YOU-side Pack. Crystal never chrome. Speak is rare. Labor is local.
